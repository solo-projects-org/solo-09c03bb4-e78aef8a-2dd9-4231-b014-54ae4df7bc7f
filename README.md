# 历史雨量档案 · 双录与复核

一个可启动的 Flask + SQLite 网页系统，用于把纸质日雨量卡片录入历史观测库。系统包含双人独立录入、扫描原图复核、裁定失效与重新核对、核定 CSV 导出，并提供 Docker Compose、四张样卡和三个演示账号。

## 快速启动

```bash
docker compose up --build
```

浏览器打开 <http://localhost:8000>。首次启动会自动建库、载入演示账号和示例卡片，数据保存在 Compose 命名卷 `archive-data` 中。

演示账号（统一密码 `demo1234`）：

| 账号 | 姓名 | 角色 |
| --- | --- | --- |
| `clerk1` | 录入员甲 | 录入员 |
| `clerk2` | 录入员乙 | 录入员 |
| `reviewer` | 复核员 | 复核员 |

建议用两个浏览器或一个无痕窗口分别登录甲、乙，以便同时进行两份独立录入。

重置演示环境：

```bash
docker compose down -v
docker compose up --build
```

## 演示路径

样卡预置了四种状态：

| 卡片 | 原图数值 | 预置状态 |
| --- | --- | --- |
| `YC-1986-0714` | 30501200 / 1986-07-14 / 42.5 mm | 两份均未录入 |
| `YC-1986-0715` | 30501210 / 1986-07-15 / 31.0 mm | 两份有出入：甲填 31，乙填 13 |
| `YC-1986-0716` | 30501220 / 1986-07-16 / 0.0 mm | 两份一致，已自动核定 |
| `YC-1986-0717` | 30501230 / 1986-07-17 / 88.0 mm | 甲已录入，等待乙 |

1. **试双录**：甲乙分别登录，打开 `YC-1986-0714`，填写同一组值（如 `42.5` 与 `42.50`）。复核员工作台会显示“两份一致 · 已核定”，CSV 中立即出现该卡。
2. **试复核**：复核员打开 `YC-1986-0715`，对照扫描样图，在甲版 `31` 和乙版 `13` 中选甲并核定。CSV 中该卡变为复核核定值 `31`。
3. **试裁定失效**：保持复核员的旧页面不刷新，让乙登录改填 `YC-1986-0715`（即使仍填 `13.0`）。保存即产生新版本，原裁定立即失效，该卡从 CSV 消失；旧页面上提交裁定会收到 **409 拒绝**，并提示以最新两份重新核对。
4. **试重新核定**：复核员重新打开卡片，按最新版本再次选定，CSV 恢复该卡。
5. **试上传**：复核员在工作台上传一张 PNG/JPEG/GIF/WebP 扫描图，选择两位录入员，即可建立新的双录任务。

## 关键业务规则

- **双人独立录入**：每张卡片固定分配给两位不同的录入员。录入员只能查看和改填自己的那一份，页面、查询和写接口都不会暴露另一位录入员的值。
- **版本化录入**：每次保存都会让 `revision` 加一，即使填写内容没有变化。
- **自动核定**：最新两份录入的站号、ISO 观测日、规范化雨量完全一致时，系统自动核定，无需复核。
- **原图裁定**：不一致时只能由复核员选择当前两份中的一份。裁定记录绑定甲、乙两份录入的 `entry id` 与 `revision`，并保存快照值。
- **裁定失效**：任一录入员保存后，该卡所有有效裁定立刻标记失效，历史记录保留用于审计；系统按最新两份重新计算，可能变为“两份一致”或继续“待复核”。
- **拒绝旧裁定**：裁定表单携带页面所见的两份版本号。提交时在 SQLite `BEGIN IMMEDIATE` 写锁内再次校验：版本、选中项或状态已变化，则返回 409 且不写入任何裁定。
- **CSV 只含当前核定**：下载时实时重算每张卡的状态，只输出当前已核定（两份一致或有效复核裁定）的卡片，每卡恰好一行。失效裁定、待复核、缺一份录入的卡都不会出现在 CSV 中。

CSV 列：

```text
card_no,station_no,observation_date,rainfall_mm,verification,verified_at
```

`verification` 为 `double_entry_agreement` 或 `reviewer_adjudication`。

## 项目结构

```text
app.py                    Flask 应用、路由、校验、核定状态机
schema.sql                SQLite 表与索引（含“每卡至多一个有效裁定”的部分唯一索引）
templates/                登录、录入、复核界面
static/style.css          页面样式
sample_cards/             四张可展示的 SVG 样卡
tests/test_app.py         业务规则与越权访问测试
Dockerfile
docker-compose.yml
```

## 配置

Compose 可通过环境变量或 `.env` 调整：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `APP_PORT` | `8000` | 宿主机端口 |
| `SECRET_KEY` | 演示默认值 | Flask 会话签名密钥；对外部署前务必更换 |
| `SESSION_COOKIE_SECURE` | `0` | HTTPS 部署时设为 `1` |

数据库与上传图保存在容器内 `/app/data`，由命名卷持久化。扫描图限制 16 MB；上传仅凭文件签名接受 PNG/JPEG/GIF/WebP，不接受可执行脚本型 SVG。

演示密码写死于初始化数据，仅适合本地试用。正式使用前应改为真实账号体系并启用 HTTPS。
